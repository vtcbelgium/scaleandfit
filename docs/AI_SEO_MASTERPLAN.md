# ScaleAndFit AI SEO & GEO Masterplan

ScaleAndFit.com uses a **Safe + Ambitious Programmatic SEO & Answer Engine Optimization (GEO)** architecture backed by verified mathematical datasets and client-side interactive utilities. Unlike thin programmatic directories, every static landing page couples deterministic measurement engines (`@vtcbelgium/scaleandfit-engines`) with a live interactive browser workspace.

## Core Design Principles

1. **Zero Scaled Content Abuse**: Every page computes exact quantitative deltas (`%` area gain, Mondopoint mm offsets, baggage liter capacity, ICAO biometric head-height windows, or SMPTE viewing distances) rather than spinning synonymous prose.
2. **Complete Linguistic Authenticity**: All programmatic pages are statically localized across 5 languages (`en`, `nl`, `fr`, `de`, `es`) with unique titles, unique meta descriptions, localized FAQ content, and reciprocal `hreflang` alternates.
3. **Answer Engine Optimization (GEO)**: Each leaf page places a direct quantitative `.geo-summary-text` capsule directly below the interactive workspace, paired with `FAQPage`, `HowTo`, `WebApplication`, `Dataset`, and `SpeakableSpecification` JSON-LD plus an open CORS-enabled `/api/specs/` JSON citation feed.
4. **Sovereign Compliance & Static Budget**: Zero third-party analytics/ad-tech tags (`ECONOMIC_VALVE_OPEN === false`), strict client-side canvas/PDF execution, and static output budget well below Cloudflare Workers' 20,000-asset threshold.

## 5-Wave Rollout & Learning Lab Roadmap

### Wave 1 — Foundation + Core Matrix Expansion (**Implemented**)
- **Scale**: `554` English base routes &rarr; **`2,825` static localized HTML pages** across `en`, `nl`, `fr`, `de`, `es`.
- **Dataset Expansion**:
  - `75` global airlines + `25` high-intent head-to-head airline baggage comparisons (`/visual-sizer/*-vs-*-cabin-bag/`).
  - `48` TV/monitor/laptop display overlays (adding SMPTE 30&deg; & THX/Cinema 40&deg; seating distance and VESA patterns) + `16` regional mattress comparisons.
  - `110` printable PDF templates (`40` dot/graph/music/isometric sheets, `40` 2026–2027 holiday planners across `20` countries, `30` Avery label layouts).
  - `120` brand-to-brand shoe fit guides + `25` single-brand Mondopoint charts (`45` footwear brands total) + `20` ISO 8653 ring size guides.
  - `90` country biometric passport/visa/ID photo specs + `25` localized retailer 4&times;6 / 10&times;15 cm print-sheet guides (`Kruidvat`, `HEMA`, `Walgreens`, `CVS`, `Boots`, `dm`, `Photomaton`, etc.).
- **Discovery & Quality Telemetry**:
  - `sitemap-index.xml` + `10` XML shards (`core-and-legal`, 4 suite shards, 5 locale shards) + complete flat `sitemap.xml`.
  - Open Citation JSON endpoints at `/api/specs/{index,airlines,displays-and-mattresses,paper-and-labels,footwear-and-rings,passport-photos}.json`.
  - Expanded `robots.txt` for AI & search crawlers (`GPTBot`, `OAI-SearchBot`, `ClaudeBot`, `PerplexityBot`, `Google-Extended`, `Applebot-Extended`), upgraded `llms.txt` / `llms-full.txt`, and automated CI build audit (`npm run seo:audit`).
